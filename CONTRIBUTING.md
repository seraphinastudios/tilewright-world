# Contributing

Direct human-written code contributions are welcome. Changes written by people
or agents follow the same review, testing and provenance rules.

- Keep the toolkit game-neutral; game specifics belong in game profiles.
- Update `docs/spec/`, fixtures and tests together for any format change.
- New code, tests and fixtures are MIT. Do not copy, adapt or depend on
  GPL/AGPL source; record any reuse of MIT-compatible outside material in
  `PROVENANCE.md`.
- Run `tools/validate.sh` before opening a pull request, and use a
  Conventional Commit title.
